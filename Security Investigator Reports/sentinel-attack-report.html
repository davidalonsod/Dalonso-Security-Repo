Sentinel Graph MCP — Blast Radius, Entity Relationships & Hunting

The sentinel-graph MCP server (https://sentinel.microsoft.com/mcp/graph) is now configured in %APPDATA%\Code\User\mcp.json and exposes the unified Sentinel exposure graph: identities, devices, IPs, files, processes, cloud resources, and incidents as a queryable graph. Use the prompts below in Copilot Chat (agent mode) to traverse blast radius and pivot across the four attack scenarios.

What the graph exposes

  • Blast radius from any seed entity (user / host / IP / file / cloud resource).
  • Entity relationships: user → device → IP → file → process → incident.
  • Cross-domain pivots: identity (Entra/Okta) ↔ endpoint (Defender) ↔ cloud (AWS/GCP) ↔ mail (Proofpoint).
  • Incident / alert traversal: which incidents touch a given entity.
  • Path queries: shortest path between two entities (e.g. external IP → Tier‑0 host).

Suggested investigation workflow

  1. Seed the graph with the highest-confidence IOC for each scenario (table above).
  2. Expand 1–2 hops to capture immediate blast radius; flag any Tier‑0 nodes touched.
  3. Cross-reference with the ThreatIntelIndicators and AbuseIPDB_Blacklist_CL tables to score external nodes.
  4. Pivot to incidents: ask the graph MCP for incidents containing the seed entity, then escalate via the sentinel-triage MCP.
  5. Containment: feed the resulting entity list into the response-mcp server (isolate_device, disable_ad_account, revoke_entra_sessions).

Combining MCP servers (multi-tool play)

  • sentinel-graph → discover blast radius + relationships.
  • sentinel-triage → fetch incidents/alerts, run Advanced Hunting on graph-discovered entities.
  • sentinel-data-exploration → query query_lake for full Log Analytics history of those entities.
  • ti-mindmap → enrich external IPs/CVEs with curated threat reports.
  • response-mcp → contain compromised identities and devices once confirmed.

Recommended Sentinel Analytics Rules (KQL)

R1 — Password spray with MDTI/TI & AbuseIPDB enrichment

let badIPs = ThreatIntelIndicators
| where IsActive == true and ObservableKey == "network-traffic:src_ref.value"
| summarize by ObservableValue;
let abuseIPs = AbuseIPDB_Blacklist_CL | summarize by IpAddress;
ASimAuthenticationEventLogs
| where TimeGenerated > ago(1h)
| where EventResult in ("Failure","Success")
| summarize Failures=countif(EventResult=="Failure"),
            Successes=countif(EventResult=="Success"),
            Users=dcount(TargetUsername)
            by SrcIpAddr
| where (Failures >= 5 and Users >= 3) or Successes > 0
| extend MDTI = iif(SrcIpAddr in (badIPs), "MDTI-hit", ""),
         AbuseIPDB = iif(SrcIpAddr in (abuseIPs), "AbuseIPDB-hit", "")
| where MDTI != "" or AbuseIPDB != "" or Failures >= 10
| project SrcIpAddr, Failures, Successes, Users, MDTI, AbuseIPDB

R2 — Ransomware behaviour on endpoints

let ransom_ext = dynamic([".locked",".encrypted",".enc",".ransom",".crypt"]);
ASimFileEventLogs
| where TimeGenerated > ago(15m)
| where ThreatCategory == "Ransomware"
   or TargetFileExtension in (ransom_ext)
   or TargetFileName has_any (ransom_ext)
| summarize Files=count(), Hosts=dcount(DvcHostname)
            by ActorUsername, ActingProcessName, bin(TimeGenerated, 5m)
| where Files >= 10 or Hosts >= 2
